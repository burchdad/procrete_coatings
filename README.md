# ProCoat Concrete Coatings

Static marketing site for ProCoat Concrete Coatings.

## What is included

- Responsive homepage in `index.html`
- Dedicated pages for projects, media/Reels, why rubber, services, process, FAQ, contact, service areas, and SEO service pages
- Polished CSS in `styles.css`
- Mobile navigation behavior in `script.js`
- Original project imagery copied into `assets/images`
- Crawling basics: `robots.txt`, `sitemap.xml`
- LocalBusiness structured data and Open Graph metadata

## Local preview

Open `index.html` in a browser, or run a tiny static server from the repo root:

```powershell
python -m http.server 4173
```

Then visit `http://localhost:4173`.
